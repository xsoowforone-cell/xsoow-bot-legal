Términos de servicio de XSOOW BOT

Última actualización: 30 de octubre de 2026

Estos términos regulan el uso de XSOOW BOT, un bot anti-spam para Discord. Al añadir el bot a un servidor o usar sus comandos, aceptas estos términos y nuestra política de privacidad. Si no estás de acuerdo, no uses el bot.

1. Qué es el servicio

XSOOW BOT revisa los mensajes de los servidores donde está instalado y, según lo que configure cada servidor, puede borrar mensajes sospechosos, silenciar o banear a sus autores, avisarles por mensaje privado y dejar un registro para el equipo del servidor. Lo desarrolla y administra una persona natural conocida en Discord como XSoow, desde Colombia ("el desarrollador").

2. Quién puede usarlo

  • Debes cumplir las Condiciones del servicio y las Normas de la comunidad de Discord, incluida la edad mínima.
  • Solo un administrador del servidor (con permiso para administrar el servidor) puede configurar el bot. Quien lo añade declara tener autoridad para hacerlo.
  • Para funcionar bien, el bot necesita estos permisos: ver canales, enviar mensajes, insertar enlaces, leer el historial, administrar mensajes y moderar miembros. Para banear automáticamente, también el permiso de banear miembros. El rol del bot debe estar por encima de los roles que debe poder moderar.

3. Uso aceptable

No puedes usar el bot para acosar, discriminar o perjudicar a otras personas, para castigar a miembros de forma abusiva, para incumplir las reglas de Discord ni para intentar dañar, copiar o saturar el servicio. Tampoco puedes intentar saltarte sus límites ni acceder a datos de otros servidores.

4. Responsabilidad de quien administra el servidor

  • El bot es una ayuda automática y puede equivocarse: puede borrar o castigar mensajes legítimos (falsos positivos) o dejar pasar spam. Cada servidor decide su nivel de sensibilidad, sus dominios y palabras permitidas y si activa el baneo automático.
  • Quien administra el servidor es responsable de cómo configura el bot y de revisar el canal de registros. Se recomienda empezar en modo prueba y ajustar antes de activarlo.
  • Quien administra el servidor debe informar a su comunidad de que usa un bot de moderación automática.

5. Versión gratuita y Premium

  • La versión gratuita ofrece la detección básica: borra enlaces, invitaciones y palabras de estafa, avisa al usuario y deja registro para el staff. La versión Premium añade, entre otras cosas, el silencio y baneo automáticos, el reconocimiento de imágenes, la detección de dominios falsos y ráfagas de mensajes, las palabras propias, elegir los canales vigilados y el soporte directo. Las funciones de cada versión pueden cambiar con el tiempo.
  • Al añadir el bot a un servidor se activa una prueba gratuita de Premium de 7 días. Se concede una sola vez por servidor y por dueño de servidor; sacar y volver a meter el bot no la reinicia. Al terminar, el servidor pasa a la versión gratuita.
  • El precio, el medio de pago y la duración se informan al contratar. Los pagos se acuerdan directamente con el desarrollador y la activación se hace por servidor; no hay cobros automáticos ni renovación sin tu consentimiento. El procedimiento de pago y activación se explica en la sección 6.
  • Si el servicio no funcionó como se describe, puedes pedir la devolución de tu pago dentro de las 48 horas siguientes a la activación de Premium en tu servidor (la primera vez que se activa un plan pagado). Esto aplica a todos los planes (mensual, de 6 meses y anual). Para pedirla, escribe a los contactos de la sección 13 indicando el ID del servidor y el comprobante de pago.
  • Si dejas de pagar o el plan vence, el servidor vuelve a la versión gratuita. No se borran tus datos de configuración por ese motivo. Para volver a Premium se contrata un plan de nuevo, como se explica en la sección 6.

  • Contratación. Los planes Premium se contratan por servidor, no por usuario. El administrador interesado elige el plan y debe proporcionar los datos necesarios para identificar el servidor (su ID) y la compra (plan y comprobante de pago). Los métodos de pago disponibles pueden variar según el plan y se muestran al contratar.

Un pago se considera confirmado únicamente cuando se verifica que el dinero llegó efectivamente. El comprobante que envías sirve como referencia para identificar la transacción, pero por sí solo no confirma el pago.
  • Activación manual. Premium no se activa automáticamente después de pagar. Primero el desarrollador verifica la recepción del dinero y después activa manualmente el plan en el servidor. El tiempo de activación puede variar según la disponibilidad del desarrollador y el tiempo necesario para comprobar la transacción. No se garantiza una activación inmediata ni un plazo fijo.
  • Pagos no confirmados. Premium permanece sin activar mientras el dinero todavía no aparezca en la cuenta, el comprobante sea incorrecto o ilegible, el importe recibido no coincida con el precio del plan, la transacción esté pendiente o no sea posible identificar a qué servidor corresponde el pago.
